This install hasn't been bootstrapped yet. Mint a setup token from the host shell to register the first instance admin.

  1. SSH to the Cypra host (or run from the project directory in dev).
  2. Run cypra admin reset-bootstrap. It prints setup_token=….
  3. Open https://<your-install-host>/setup/<token> in this browser.

In a typical local dev setup the command is:

go run ./cmd/cypra admin reset-bootstrap
