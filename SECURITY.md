# Security Policy

## Supported Versions

Cypra has not shipped a public release yet. Security fixes target `main` until the first tagged release.

## Reporting a Vulnerability

Report vulnerabilities privately to `cypra@watzon.dev`.

Include:

- Affected commit or version.
- Reproduction steps.
- Expected and actual impact.
- Any proof-of-concept code or logs with secrets removed.

Do not include raw production secrets, tokens, private keys, database dumps, or personal data in reports.

## Disclosure

Maintainers will acknowledge valid reports, coordinate a fix, and publish disclosure notes after users have a reasonable update window.
